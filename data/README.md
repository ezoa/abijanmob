# Données — AbidjanMob (prototype)

## `corpus/network.json`

Corpus pilote du corridor **Cocody–Plateau–Adjamé** (élargi à quelques communes pour la
réalisme des scénarios de démonstration) :

- **20 arrêts**, **12 lignes** (4 gbakas, 5 woro-woro, 2 bus SOTRA, 1 bateau-bus)
- **14 points d'intérêt** (POI) pour la recherche d'itinéraires
- **1 conducteur** de démonstration (Koffi Assamoi, Gbaka Riviera 3 – Adjamé)

## ⚠️ Avertissement — données indicatives

Les tracés, positions d'arrêts, tarifs et fréquences sont **approximatifs et indicatifs**,
établis pour les besoins du prototype de démonstration AIMD (septembre 2026). Ils ne
constituent pas une donnée terrain. Ils seront remplacés par les enquêtes terrain de M0
(octobre 2026, cf. `docs/plan-mvp.md`) puis enrichis par la boucle
« paiement → donnée ».
